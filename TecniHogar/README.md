# TecniHogar - Laboratorio 3: Herencia

TecniHogar es una aplicación de consola desarrollada en Java para administrar servicios técnicos a domicilio.

El programa utiliza herencia y polimorfismo para manejar diferentes categorías de servicios, cada una con sus propias reglas de costo, tiempo de atención, compatibilidad con cuadrillas y cantidad máxima de visitas.

## Funciones del programa

- Cotizar y registrar órdenes de servicio.
- Registrar y consultar cuadrillas.
- Crear jornadas de trabajo.
- Asignar y retirar órdenes.
- Iniciar jornadas.
- Registrar visitas completadas o fallidas.
- Controlar el límite de visitas de cada servicio.
- Consultar órdenes y cuadrillas.
- Generar reportes de órdenes, jornadas e ingresos.
- Validar operaciones incorrectas sin cerrar el programa.

## Categorías de servicio
